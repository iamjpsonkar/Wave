## Repository conventions

- `src/` — application source and browser storage adapters.
- `tests/` — Node storage tests and Playwright browser journeys.
- `.github/workflows/` — CI automation.
- `docker/` — static web-server configuration for the container image.
- `docs/` — maintained product, architecture, compatibility and deployment documentation.

The root-level feature catalogues and engineering registers are intentionally retained: they have distinct purposes and contain project decisions/history. This index provides navigation; it does not replace or consolidate those records.
